The user requests visual refinement of project creation without changing its content or business logic. The current screenshots have floating/nested cards, oversized detached actions, uneven content density, repeated decorative icons/green rules and competing summary emphasis.

ServiceNow Horizon's [form guidance](https://horizon.servicenow.com/workspace/patterns/forms/form-patterns) emphasizes logical field grouping, recognizable control states, responsive organization and actions that reflect task scope. Its [grid guidance](https://horizon.servicenow.com/workspace/foundations/grids-and-layouts) explains consistent alignment and the complexity introduced by extra containers. This proposal applies those principles using ProjectWing's existing neutral/green tokens and public controls; it does not reproduce ServiceNow branding or claim certification.

## Proposed presentation

- A compact step rail marks the current step without a wide decorative connector.
- A single quiet form surface, consistent section rhythm and aligned field/help/error positions replace stacked cards and decorative green dividers.
- Native radio semantics provide explicit single selection for source and initialization; selected appearance does not depend on color alone.
- The summary remains visible as secondary metadata beside the form, then moves below it on narrow widths. It no longer resembles a competing primary card.
- Normal-sized actions remain in the form's own footer flow. Sticky behavior does not remove their occupied space or overlap fields.
- Existing brand colors, focus behavior, label associations, disabled/read-only distinctions and dark-theme support remain part of the contract.
