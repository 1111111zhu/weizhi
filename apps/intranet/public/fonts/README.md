# Launcher editorial typeface

`noto-serif-sc-launcher.woff2` is the Google Fonts Noto Serif SC subset for the fixed Chinese and English launcher headings/descriptions, requested at weights 400 and 600. The provider returns the same variable WOFF2 for both weights. Size: 13,916 bytes. Retrieved 2026-09-15.

Source family: https://github.com/google/fonts/tree/main/ofl/notoserifsc License: SIL Open Font License 1.1, retained in `NotoSerifSC-OFL.txt`. Distributed by the Google Fonts CSS API and fonts.gstatic.com.

Subset text: `工作台近期通知项目管理客户工时制度与资料WorkspaceRecent noticesProjectsClientsTimesheetsPolicies & guides`

The application serves this font locally. No runtime Google Fonts request is required. This subset is not for user-generated text; arbitrary notice titles retain the standard UI font. Regenerate the subset and CSS unicode-range if the fixed editorial copy changes. Do not add unavailable glyphs expecting consistent CJK serif fallbacks on Android.
